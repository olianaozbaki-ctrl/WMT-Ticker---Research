# Generated Outputs

- `phase2_results.json` is the machine-readable executed result.
- `phase2_results.md` is the visible result for a grader who does not run the code.

All four files are overwritten only by `python scripts/generate_phase2_results.py`. The Phase 4A decision-support files summarize the four-outcome decision framework, stress-window dispersion, non-authorizing model envelope, outstanding evidence, stop conditions, and committee decisions. They flag the October 5 stress-date CPI look-ahead mismatch. No results are manually transcribed or treated as a final investment judgment.
