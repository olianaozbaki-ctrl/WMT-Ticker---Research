# Generated Outputs

- `phase2_results.json` is the machine-readable executed result.
- `phase2_results.md` is the visible result for a grader who does not run the code.

All generated outputs are overwritten only by `PYTHONPATH=src python scripts/generate_phase2_results.py`. Results use BLS August 2026 CPI-U data released September 11, the DGS10 observation available October 5, and ETF adjusted-price observations through September 30, 2026. The reports retain the original CPI look-ahead as validation history, show stress-window dispersion, evidence gates and stop conditions, and do not make a final investment judgment.
